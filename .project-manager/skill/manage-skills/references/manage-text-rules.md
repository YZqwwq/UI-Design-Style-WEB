# 轻量文本规则管理

## 编写入口

编写或审阅规则正文前，读取项目根目录下 `.project-manager/rule/README.md`。该文件统一维护轻量写法、路径基准，以及引用 skills、项目文档、参考资料和其他规则的定位要求；本文件只负责创建、登记和维护流程，不另存一份写法规范。

## 创建与更新

1. 从用户明确要求或已有项目约定提取方向，不能由框架、目录或一次设计选择推断长期偏好。只针对当前任务的口头补充默认留在当前任务，不自动持久化；用户要求记录阶段补充时写明有效期或结束条件。
2. 检查现有相关规则，修改对应文件，避免同一偏好多份维护；保留无关内容和必要例外。路径基准与引用方式遵循 rule/README.md。
3. 更新 `AGENTS.md` 的文本规则地图，登记领域、适用范围与有效期、实际文件路径；存在优先入口时同步对应地图。地图只帮助判断加载，不展开规则正文。
4. 规则引用非全局 skill 且需要接入时，按 skill 接入流程复制后登记；引用全局 skill 时使用实际路径。普通风格图片或参考文档不因为被引用就作为 skill 复制，不主动扫描所有参考。
5. 规则的变更、失效或移除要让当前工作停止沿用旧要求。取消适用或取消登记不默认删除文件；用户要求清理时再处理相关文件与引用。
