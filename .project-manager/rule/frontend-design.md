# 前端设计规则

适用范围：本项目所有前端页面、组件和交互的设计、开发、修改与审阅；仅修改非界面逻辑时不加载。
有效期：长期适用，直到用户明确调整或取消。

## 大屏与小屏适配

- 所有设计都必须同时考虑大屏与小屏，结合可用空间调整布局、信息层级与操作方式，不能只完成单一屏幕尺寸。
- 大屏合理利用空间，控制内容宽度、行长和模块密度，避免机械拉伸；小屏按阅读和操作顺序重排，保证文字可读、控件可操作。
- 同时考虑中间宽度、长文本和内容增长，避免遮挡、截断与非预期的横向溢出；不能通过隐藏必要内容完成适配。
- 界面变更应检查具有代表性的大屏、小屏及布局切换位置。未实际验证的适配效果应如实说明。

## 形状与 UI 语义

- 胶囊、矩形与圆角矩形的选择应服务于组件用途、信息层级和交互含义，不能仅为装饰随意替换。
- 胶囊通常用于简短标签、状态、筛选项或紧凑操作；矩形与圆角矩形通常用于内容容器、输入区域和结构化操作。根据场景选择，不将形状与单一功能绝对绑定。
- 同类用途保持一致的形状与圆角尺度，不同用途需要清晰区分；避免所有元素一律胶囊化，或无意义地混用形状。
- 可点击控件与纯展示信息应清楚区分，结合文字、边界和交互状态表达用途，不仅依靠形状传达含义。

## 空间设计

- 将留白、间距、对齐、内边距和内容密度作为设计的一部分，用空间建立层级与阅读顺序。
- 相关内容靠近，不同分组之间保留更明显的间隔；同层级模块与重复组件保持一致的间距节奏。
- 区分容器内边距、元素间距和模块间距，避免随意堆叠空白或挤压内容；随屏幕空间调整，保留必要的视觉呼吸感与操作空间。

## 默认无感滚动

- 除非用户明确要求显示滚动条，所有滚动区域默认采用无可见滚动条的设计，包括页面、弹窗和局部横向或纵向滚动容器。
- 隐藏滚动条时必须保留正常滚动能力，支持适用的触摸、滚轮、触控板与键盘操作；不能用禁用滚动或裁切内容代替隐藏滚动条。
- 保证内容与焦点可达。局部滚动区域在需要时通过内容露出、布局或轻量提示表达仍有内容，避免隐藏滚动条后无法发现后续内容。
- 尽量避免不必要的嵌套滚动；确需嵌套时，保证滚动区域和操作归属清晰。
