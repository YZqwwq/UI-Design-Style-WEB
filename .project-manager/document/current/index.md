# 当前能力概览

设计图鉴（Design Atlas）定位为个人设计收集库，保留现有设计，目标支持自定义风格分类和跨风格 UI 组合，见[产品定位与目标](../goals.md)。前端设计库使用原生 HTML/CSS/JavaScript，独立登录组件使用 React/TypeScript、Tailwind 与 shadcn 风格 Button，后端采用 Fastify 5 + TypeScript，通过 pg 连接远程 PostgreSQL。

个人设计、分类与标签管理已实现；跨风格 UI 组合编辑与保存尚未实现；当前的“组合筛选”仅指多个筛选条件取交集。

## 仓库组织

数据库环境已明确拆分：开发、默认检查/迁移及集成测试读取 `.env` / `.ENV` 中的 `PGDATABASE-test`、`PGUSER-test`、`PGPASSWORD-test`；`npm start` 与显式 `:prod` 数据库命令读取无后缀的正式凭据。开发凭据缺失或库名与正式库相同时拒绝连接，不能回退。环境由启动入口选择，不受 NODE_ENV 隐式切换影响。最新只读连接验证指向 UI-test（PostgreSQL 18.6），账号表尚未初始化；未对远端运行迁移或写入测试，账号权限隔离未验证。

根目录使用 npm workspaces：`apps/web` 管理前端和 Vite，`apps/api` 管理 Fastify、数据库迁移、种子与后端测试。根目录 `.project-manager/` 和 `AGENTS.md` 统一管理前后端，未在应用目录复制管理规则。数据库 `.env` 仍位于根目录，后端按模块位置定位，不受启动目录影响。

## 页面主题

站点导航、搜索、筛选、卡片信息区、详情表单、反馈与按钮统一为黑白灰中性色，主操作为黑底白字。主题变量集中在 `apps/web/src/style.css` 的 `:root`；卡片中的设计预览及配色色块保留原风格颜色。

## 页面区域

顶部导航承接品牌入口、全局搜索、登录/注册、当前账号、退出与结果数量；左侧栏陈列分类、标签和清除筛选，从视窗顶部贯穿到底部，桌面顶部导航与内容区从侧栏右侧开始，收起后保留 64px 窄栏及展开图标（手机为 56px）。中间区域仅展示设计卡片和必要的加载、空状态及失败反馈，不放宣传介绍或独立装饰图标；当前收集库页面没有底部脚注。访客默认浏览公开初始化模板，只有点击右上角 Sign in 才打开居中登录/注册弹窗（半透明玻璃遮罩与背景模糊）；退出或登录过期后返回公开模板。

选择卡片后，右侧属性栏展示该设计的说明、布局、字体、配色和可编辑提示词；复制操作集中在属性栏。大屏与内容区并排，中间屏宽使用右侧覆盖面板，手机使用全屏属性面板；覆盖模式使用原生模态对话框管理焦点。属性栏打开后卡片显示选中边框，关闭后焦点回到对应卡片。分类栏在手机默认收起。侧栏展开宽度桌面为 300px、大屏为 320px、中间宽度为 280px；展开/收起图标位于侧栏顶部，提供悬停提示与无障碍名称。

## 2026-10-11 用户系统改进

本轮采用单机单服务进程，不使用 Redis，不增加用户角色。后端在会话、参数校验和 owner_id 限定查询处执行访问控制，公开模板不可写；浏览器仅操作 API 返回的本人数据。

- 注册、模板复制及会话签发统一在一个事务，失败完整回滚；登录签发、改密及全部注销通过账号行锁协调。改密验证当前密码及两次新密码，成功撤销全部会话。
- 个人设计、分类和标签具有增删改接口与界面；仍被使用的分类和标签不能删除。接口拒绝额外 owner_id/role 字段，分类和标签引用限定本人。入口见 apps/api/src/library.ts、apps/web/src/library-ui.js。
- 前端注册表单不执行密码一致性判断；后端接收 confirmation 并验证。会话恢复通过版本号协调，旧响应不能覆盖新状态；关闭认证弹窗后仍核对服务器最终会话。
- Windows 开发及构建工具改为 Node 直接启动，避免 & 路径的 .cmd 解析问题；规则测试将符号链接权限依赖独立出来。
- 本轮使用 PostgreSQL 17 临时容器，未操作已有业务数据库。数据库测试覆盖跨用户写入、分类引用保护、会话撤销和注册失败回滚。更早的浏览器/数据库验证记录保留其原有日期与范围。

密码找回、第三方登录及跨风格组合仍未实现。本轮没有增加数据库迁移，不改动现有表结构。
