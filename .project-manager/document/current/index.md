# 初步能力概览

设计图鉴（Design Atlas）定位为个人设计收集库，保留现有设计，目标支持自定义风格分类和跨风格 UI 组合，见[产品定位与目标](../goals.md)。当前实现提供设计风格浏览、分类筛选与单个设计的 AI 提示词生成，使用原生 HTML/CSS/JavaScript。

自定义分类管理、跨风格 UI 组合编辑与保存尚未实现；下表中的“组合筛选”仅指筛选条件组合。

## 当前可见能力

| 能力 | 浅层可见行为 | 依据 |
| --- | --- | --- |
| 风格目录 | 数据包含 8 个风格示例，页面按数据生成预览卡片；顶部集中搜索、分类与标签筛选，卡片区域按屏宽呈现三列、两列或单列；README 声明有 6 类设计方向 | [目录数据](../../../src/catalog.js)、[页面逻辑](../../../src/app.js) |
| 组合筛选 | 按分类、标签和关键词筛选，页面提供结果数量、空状态和重置操作 | [筛选逻辑](../../../src/catalog.js)、[页面逻辑](../../../src/app.js) |
| 风格详情 | 展示风格预览、配色、排版、布局和适用场景 | [页面逻辑](../../../src/app.js) |
| 提示词生成 | 根据风格与项目用途生成提示词；README 描述支持编辑、复制与复制失败时的手动处理 | [生成逻辑](../../../src/catalog.js)、[项目说明](../../../README.md) |
| 本地开发与静态构建 | package.json 提供 dev、test、build 命令，声明 Node.js >=18 | [项目配置](../../../package.json) |

## 边界

README 声明预览为原创 HTML/CSS 示例，用途与提示词不上传、不持久化，并支持移动端与键盘操作；本次已检查页面结构、交互与样式，运行现有测试和构建，并在本地 Chrome 验证 320、390、760、761、1024、1100、1440、1920px 宽度无页面横向溢出；已查看桌面与手机截图，验证分类、标签、搜索空状态、重置、详情打开、Escape 关闭、用途更新及搜索快捷键。剪贴板写入与其他浏览器兼容性未在本次验证，不将局部验证等同于全部行为验证通过。

项目管理已接入规则编写规范、manage-skills 与 manage-documents；尚未添加业务文本规则或额外业务 skills。
