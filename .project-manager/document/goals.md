# 产品定位与目标

## 定位

设计图鉴是个人设计收集库，服务于个人对设计参考的积累、整理、查找和复用。当前已有设计全部保留，作为库中的初始内容继续使用。

项目不定位为设计交流广场；社区发布、评论、关注、排行榜等社交分发能力不属于当前已明确的核心目标。

## 用户已明确的核心方向

| 方向 | 目标含义 |
| --- | --- |
| 个人收集 | 围绕自己的设计参考组织内容，现有设计继续保留，不因定位调整而清空或替换 |
| 风格分类自定义 | 用户能够按自己的理解定义和调整风格分类；现有分类是初始组织方式，不是不可变的分类体系 |
| UI 组合自定义 | 允许跨不同风格选择和组合 UI，形成自己的设计方案，不局限于选择一套完整的预设风格 |
| 展示优先 | 页面保持简洁，把主要空间留给设计卡片；搜索和管理入口优先集中于导航区域 |
| 清晰可读 | 保留舒适字号、行高和间距，同时适配大屏与小屏，不通过缩小文字堆放功能 |

跨风格组合的示意：同一方案可以使用一种风格的导航与另一种风格的内容卡片。此例用于解释目标，不表示具体组件粒度、编辑器形式或组合规则已确定。

## 当前实现与目标的区别

目前已有设计卡片浏览、分类与标签筛选、关键词搜索、设计详情和单个设计的提示词生成。设计数据由源码维护；页面没有自定义分类管理、跨风格 UI 组合编辑或组合保存能力。

“分类、标签和关键词组合筛选”是多个筛选条件共同检索设计，不是把不同风格的 UI 组合成方案。编辑单个设计的提示词也不等于具备 UI 组合能力。

自定义分类与跨风格 UI 组合属于已确认的产品方向，尚待实现。组合粒度、操作方式、个人数据存储和导入方式未在本次定位中确定；不据此假定已有账户、云同步或可视化拖拽编辑器。

## 后续设计与实现依据

后续功能围绕个人收集、整理与组合复用展开。新增管理功能应延续简洁导航与卡片展示的布局，保留现有内容和浏览能力。

本文记录产品目标与边界，不是功能已完成的声明，也不构成具体阶段排期。实际能力和验证记录以 [当前概览](current/index.md) 与 [文档索引](index.md) 为准。
