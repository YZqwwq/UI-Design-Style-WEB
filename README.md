# 设计图鉴 · Design Atlas

展示和分类设计风格，将选中设计的视觉规范转换为可复制给 AI 的提示词。首版为中文、本地静态网站，使用原生 HTML/CSS/JavaScript，无第三方运行依赖。

## 运行

需要 Node.js 18 或以上。在此目录运行 `npm run dev`，打开 http://127.0.0.1:4173 。可通过 `PORT` 环境变量更改端口。请通过 HTTP 访问，不要直接双击 HTML（ES modules 需要本地服务器）。

- `npm test`：验证数据完整性、组合筛选和提示词生成。
- `npm run build`：将公开页面资源复制到 `dist/`，可用静态服务器托管。部署在站点根路径。

## 当前功能

- 8 种原创 HTML/CSS 风格示例，6 类设计方向。
- 分类、标签和关键词组合筛选，空结果和重置。
- 设计详情、色值、排版及布局说明。
- 可填写项目用途、编辑提示词并复制；自动复制失败时选中文本供手动复制。
- 移动端布局、原生对话框键盘操作及减少动画偏好。

修改 `src/catalog.js` 扩充设计数据，并在 `src/style.css` 中提供对应 `tone` 的预览。预览由项目维护的可信数据生成，不接受用户提供的 HTML。详情用途与提示词仅在当前页面内使用，不上传、不持久化。示例不是外部网站截图。

项目管理入口为 `AGENTS.md`；目标、现状和实际验证边界见 `.project-manager/document/index.md`。同级 `project-manager` 仓库负责管理 skill 本体，此仓库保留接入后的规范副本。
